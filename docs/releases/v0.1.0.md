# DS Bot v0.1.0

## 中文

DS Bot App 分支的首个插件与 Android App 配套版本。两端版本均为 `0.1.0`，本分支版本序列独立于上游；已移植的上游功能保留。模型与工具运行在你的电脑或 DSH 服务器，手机作为客户端连接，主机需要保持运行。

### 下载与安装

| 文件 | 用途 |
| --- | --- |
| `ds-bot-0.1.0.tgz` | 电脑/服务器上的 DSH 插件 |
| `dsbot-android-arm64-v0.1.0.apk` | Android ARM64 手机 |
| `dsbot-android-x86_64-v0.1.0.apk` | Android x86_64 模拟器 |
| `DeepSeekBot.cer` | Android 签名公开证书 |
| `SHA256SUMS` | 上述文件的 SHA-256 校验和 |

在 DSH「插件 → 添加插件」填写 `.tgz` 完整路径，启用并重启；在手机安装 ARM64 APK。电脑 DS Bot 设置启用手机连接，手机扫描二维码，电脑批准设备即可连接。无需域名、额外 App 或手动安装证书。

[完整安装教程](https://github.com/QingJ01/DS-Bot-App/blob/v0.1.0/docs/getting-started.zh.md) · [签名与发布教程](https://github.com/QingJ01/DS-Bot-App/blob/v0.1.0/docs/releasing.zh.md)

### 本版功能

- Bot 与团队群聊、流式回复、图片/文件、语音输入与语音对话、专属工具结果和操作批准界面。
- 定时任务、记忆和用量页面；Skills、插件和连接器管理；主机明确启用后的桌面浏览器控制。
- 一键本地 HTTPS、主机公钥验证、电脑批准配对与设备撤销。
- Android 后台运行通知服务，无需 FCM/APNs；可选 Expo 云推送接口。
- 中英文、浅色/夜间模式、原创鱼形入口与启动动画、悬浮胶囊输入框、消息长按操作。
- 上游 Bot 点名与会话引用、群聊交付与审批、权限沿用、模型拒绝恢复、存储保护及日志脱敏更新。
- GitHub Actions 验证、打包并构建两种 Android 架构，使用 DeepSeekBot 项目证书签名并校验。

### 使用范围

DSH 集成基线 `0.2.0-rc.2`，兼容性 CI 另检查 `0.2.1-alpha.1`。语音需要主机 Voice Input/FFmpeg；桌面浏览器需要 DSH Desktop 与对应能力。无 FCM/APNs 的通知需要 Android 服务仍在运行、手机能连接主机；不保证强制停止或系统终止后的通知。iOS 源码包含在仓库，本版不提供 IPA，尚未完成 iOS 编译与真机验证。模拟器和自动化验证不代表所有真机行为均已验证。

旧调试签名 APK 需先卸载后重装并重新配对；已有同一 DeepSeekBot 项目签名的 APK 可直接更新，主机 Bot 与聊天数据保留。不要用 npm 上游的同名 `ds-bot` 替代本版插件包。

## English

The first coordinated host-plugin and Android release of the DS Bot App fork. Both packages use `0.1.0`; this fork has an independent version series and retains the ported upstream features. Your DSH computer/server runs models and tools and must stay on.

Download `ds-bot-0.1.0.tgz` for DSH, `dsbot-android-arm64-v0.1.0.apk` for Android phones, or `dsbot-android-x86_64-v0.1.0.apk` for emulators. Add the plugin by its absolute path in DSH, enable it and restart. Install the APK, enable phone connection on the host, scan its QR and approve the device on the computer. No domain, additional app or manual certificate installation is required.

This release includes Bot/team chats, streaming, attachments, voice, tool results and approvals; tasks, memory and usage; Skills/plugins/connectors management; optional host-approved desktop browser control; local HTTPS with pinned host identity; Android runtime notifications without FCM/APNs; Chinese/English, light/dark themes, the original fish animation and floating chat controls. GitHub Actions tests, packages, builds and signs both APK architectures with the DeepSeekBot project certificate.

The DSH baseline is `0.2.0-rc.2`, with compatibility CI for `0.2.1-alpha.1`. Voice and desktop browser features require the corresponding host capabilities. Runtime notifications need a reachable host and an Android service that the OS keeps running; force-stop/termination is not covered. iOS source is included, but no IPA or verified iOS build/device test is provided. Earlier debug-signed APKs require uninstall/reinstall and pairing again; host data remains. Do not substitute the upstream npm package for this fork's tarball.

[Installation](https://github.com/QingJ01/DS-Bot-App/blob/v0.1.0/docs/getting-started.md) · [Signing and releases](https://github.com/QingJ01/DS-Bot-App/blob/v0.1.0/docs/releasing.md). Verify all downloads with `SHA256SUMS`; `DeepSeekBot.cer` is the public signing certificate.
