# DS Bot v0.1.0

## 中文

同步上游 [DS Bot v0.1.4](https://github.com/Fei2411/DeepSeek-Bot/releases/tag/v0.1.4)，并发布配套的 DSH 插件和 Android App。上游源码基线为 `5c2726279d3bcabaad6aea403c46c88fcf9ba8d8`；本分支版本序列独立，两端版本均为 `0.1.0`。

本次按维护者要求重新发布此前撤回的 v0.1.0，原始源码保存在 [`archive/withdrawn-v0.1.0`](https://github.com/QingJ01/DS-Bot-App/tree/archive/withdrawn-v0.1.0)。请重新下载本次配套文件；后续版本使用新的版本号。

### 下载与安装

| 文件 | 用途 |
| --- | --- |
| `ds-bot-0.1.0.tgz` | 电脑/服务器上的 DSH 插件 |
| `dsbot-android-arm64-v0.1.0.apk` | Android ARM64 手机 |
| `dsbot-android-x86_64-v0.1.0.apk` | Android x86_64 模拟器 |
| `DeepSeekBot.cer` | Android 签名公开证书 |
| `SHA256SUMS` | 上述文件的 SHA-256 校验和 |

在 DSH「插件 → 添加插件」填写 `.tgz` 完整路径，启用并重启；手机安装 ARM64 APK。电脑 DS Bot 设置启用手机连接，手机扫描二维码，电脑批准设备即可连接。在两端网络可直达的情况下，无需域名、额外 App 或手动安装证书。

[完整安装教程](https://github.com/QingJ01/DS-Bot-App/blob/v0.1.0/docs/getting-started.zh.md) · [签名与发布教程](https://github.com/QingJ01/DS-Bot-App/blob/v0.1.0/docs/releasing.zh.md)

### 上游更新与手机端适配

- **共享能力库：** 在电脑配置 MCP 服务、Skills 与能力包，按 Bot 分配。手机新增能力页面，可选择每个 Bot 的能力、查看连接和审批状态；MCP 命令审批和凭据配置在电脑完成。
- **重启后继续任务：** 同步上游的任务恢复与审批持久化；手机将恢复、暂停及成员工作事件显示为中英文系统消息。
- **群成员独立工作：** 查看当前群内成员的工作和待批准状态，在群详情停止指定成员任务；其他群和单人会话的状态不会混入。
- **审批提醒与群聊改进：** 对话列表标记待批准任务，保留手机批准界面；同步上游群聊交付、延迟回复、Bot 点名及模型工具调用恢复改进。
- **聊天控件修复：** 输入框只保留品牌蓝色发送按钮；空输入框和左侧小圆形加号对齐，长文本可增长。保留无阴影的悬浮胶囊、透明间隙、长按消息操作、设置入口、中英文与夜间模式。
- **主机手机入口：** 设置中的手机设备页面中文翻译，以及侧栏底部左侧鲸鱼、手机两枚按钮。

同时保留 Bot/群聊、图片与文件、语音、专属工具结果、定时任务、记忆、用量、Skills/插件/连接器管理、主机明确启用后的桌面浏览器控制、一键本地 HTTPS 与公钥验证、设备批准及撤销、Android 运行时通知等现有功能。

### 验证与使用范围

发布前运行插件 582 项、App 62 项、SDK 28 项、设备助手 8 项测试；插件生成文件检查和 lint 通过。官方 npm DSH `0.2.0-rc.2` 的隔离模拟模型联调完成 36 步，覆盖共享 MCP/Skill 使用、群成员能力隔离和移除能力。GitHub Actions 进一步检查 Linux/Windows、Node 22/24、DSH `0.2.0-rc.2` 与 `0.2.1-alpha.1`，构建并使用 DeepSeekBot 项目证书签名两种 Android 架构。

模型和工具运行在你的电脑或 DSH 服务器，主机需要保持运行。语音需要主机 Voice Input/FFmpeg；桌面浏览器需要 DSH Desktop 与对应能力。无需 FCM/APNs 的通知依赖 Android 服务仍在运行、手机能连接主机，不覆盖强制停止或系统终止。iOS 源码包含在仓库，本版不提供 IPA，尚未完成 iOS 编译与真机验证。模拟模型和模拟器验证不代表生产模型效果或所有真机行为。

使用同一 DeepSeekBot 项目签名的 APK 可以直接更新，电脑上的 Bot 与聊天数据保留。旧调试签名 APK 需先卸载再安装并重新配对。不要用 npm 上游同名 `ds-bot` 替代本版插件包；下载后可用 `SHA256SUMS` 校验。

## English

This coordinated plugin and Android release ports upstream [DS Bot v0.1.4](https://github.com/Fei2411/DeepSeek-Bot/releases/tag/v0.1.4), source commit `5c2726279d3bcabaad6aea403c46c88fcf9ba8d8`. Both fork packages remain `0.1.0` in their independent version series. At the maintainer's request, this replaces the withdrawn v0.1.0; the original source is preserved under [`archive/withdrawn-v0.1.0`](https://github.com/QingJ01/DS-Bot-App/tree/archive/withdrawn-v0.1.0). Download the newly matched files. Future releases use new version numbers.

New upstream features include a shared MCP/Skill/capability-pack library, restart recovery, persistent approval reminders and independent group-member work. The App can assign configured capabilities to each Bot, display connection/approval status and localized system events, mark conversations waiting for approval, and stop a member's task from group details. MCP configuration, credentials and command approval remain on the computer. Mobile state excludes command configuration and credentials and scopes work/actions to the owned conversation.

The release also fixes floating chat controls: one blue send button, a smaller circular attachment button aligned with an empty composer, expanding multiline input, transparent gaps and no capsule shadows. Existing Bot/group chats, media, voice, tool results, approvals, tasks, memory, usage, Skills/plugins/connectors management, optional desktop browser control, pinned local HTTPS, device management, Android runtime notifications and Chinese/English light/dark interfaces remain available.

Use `ds-bot-0.1.0.tgz` for DSH, the signed ARM64 APK for Android phones, or the x86_64 APK for emulators. Add the plugin by its absolute path, enable it and restart. Install the App, enable phone connection on the host, scan its QR and approve the device on the computer. Reachable local networking needs no domain, additional app or manual certificate installation. Verify downloads with `SHA256SUMS`; `DeepSeekBot.cer` is the public signing certificate. Same-project signed APKs can update in place; debug-signed builds require uninstall/reinstall and pairing again. Host data stays on the computer.

Validation includes 582 plugin tests, 62 App tests, 28 SDK tests, 8 device-helper tests, generated-client consistency, lint, and a 36-step real DSH/mock-model smoke test. Actions checks Linux/Windows, Node 22/24 and DSH `0.2.0-rc.2`/`0.2.1-alpha.1`, then builds and signs both Android architectures. The host must stay on. Voice/browser features require their host capabilities. Runtime notifications need a reachable host and a running Android service; force-stop/termination is not covered. iOS source is included without an IPA or verified iOS build/device test. Emulator/mock-model results do not establish production-model quality or every physical-device behavior.
