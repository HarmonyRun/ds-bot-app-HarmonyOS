# DS Bot v0.1.1 · 修订 2 / Revision 2

## 中文

修复手机首页的新消息排序：置顶会话仍优先，其余 Bot、群聊与 Agent 会话按最近活跃时间排列。Chief 保留首页大头像入口与列表项，但列表项不再无条件占据首位。

- 主机提供会话最近更新时间；桌面或其他设备产生新消息时，手机列表自动更新位置与时间。
- 回到首页会立即刷新；预览也随会话活动更新，不再只依赖通知。最新活跃的会话优先加载预览，保留其他会话缓存。
- 图片或文件消息也可更新预览。离线或旧主机仍可使用已缓存消息时间排序。

## English

For plugin installation or reinstallation, paste the complete GitHub specification shown above into **DSH → Plugins → Add plugin**, install, enable and restart. No archive download or helper is needed. [Installation and troubleshooting](https://github.com/QingJ01/DS-Bot-App/blob/main/docs/plugin-install-recovery.md).

Revision 2 fixes recent-activity ordering on the phone. Explicitly pinned conversations remain first; other Bot, group and Agent conversations sort by their latest activity. Chief keeps its home shortcut and conversation row without permanently occupying the first list position.

Host summaries expose update timestamps, home previews refresh when activity changes, and returning home refreshes the workspace immediately. Recent conversations get preview priority while existing cache entries remain available. Attachment messages update previews, and cached message timestamps provide a fallback for offline or older hosts.

Update both ends using `ds-bot-0.1.1-r2.tgz` and the matching `dsbot-android-arm64-v0.1.1-r2.apk` (or x86_64 for emulators). Version names remain `0.1.1`; the Android versionCode increases and the existing signing identity is retained. Restart DSH after updating the plugin. Host conversations remain intact. Verify the revision files with `SHA256SUMS-r2` and the shared `DeepSeekBot.cer`.

The revised source is tagged [`v0.1.1-r2`](https://github.com/QingJ01/DS-Bot-App/tree/v0.1.1-r2). The original `v0.1.1` tag and assets are preserved byte-for-byte so existing pnpm lockfiles retain their recorded integrity. Assets without `r2` on this Release page are the original build.

Pre-revision checks pass 767 local tests, TypeScript, generated-client consistency and lint, plus real isolated DSH/mock ordering and preview checks. Actions rebuilds and signs both Android architectures. iOS devices and screen readers remain unverified. All previous IPv6, working-folder, tool-result and UI improvements remain included. [Installation](https://github.com/QingJ01/DS-Bot-App/blob/main/docs/getting-started.md).
