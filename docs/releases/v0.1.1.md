# DS Bot v0.1.1

## 中文

同步上游 [v0.1.5](https://github.com/Fei2411/DeepSeek-Bot/releases/tag/v0.1.5)，新增 IPv6 直连与手机工作目录管理，并改善目录选择、插件页面和中英文界面。配套 DSH 插件和 Android App 均为 `0.1.1`。

### 更新内容

- **IPv6 直连：** 自动列出可用的内网／公网 IPv6 地址，生成 IP 证书与配对链接。公网 IPv6 可以跨网络连接，前提是手机网络支持 IPv6，路由器和主机防火墙允许入站；无需域名或本项目中继服务。
- **工作目录：** 在手机 Bot／群聊详情选择主机项目、输入完整路径，或使用主机提供的目录浏览器。横向路径导航自动显示当前目录，浏览与输入分别确认；切换目录保留历史，并在新的会话分段继续。
- **工具结果：** 支持 PTC 子工具状态与结果、已交付文件摘要，以及主机可提供的文件变更统计。手机文件卡片展示元数据，不等同于文件下载；消息附件仍使用原有下载／预览功能。
- **界面细节：** 补齐插件运行状态、插件描述和思考级别的中文；插件列表并排切换，群聊作者与思考详情的点击区域扩大到 44dp。默认蓝色统一为 `#3964FE`，保留悬浮控件、无阴影胶囊、长按消息操作与夜间模式。
- **上游修复：** 同步提问与问候行为、未读消息积压控制、模型会话标识、记忆重试、PTC 群活动、原生桌面文件卡片、工作详情偏好和 DSH 数据目录解析等改进。旧版主机缺少工作目录 API 时，手机明确提示更新，不会误报保存成功。

### 下载、安装与升级

| 文件 | 用途 |
| --- | --- |
| `ds-bot-0.1.1.tgz` | 电脑／服务器上的 DSH 插件 |
| `dsbot-android-arm64-v0.1.1.apk` | Android ARM64 手机 |
| `dsbot-android-x86_64-v0.1.1.apk` | Android x86_64 模拟器 |
| `DeepSeekBot.cer` | Android 签名公开证书 |
| `SHA256SUMS` | 发布文件校验和 |

更新时请同时安装本版插件与 App。DSH「插件 → 添加插件」选择 `.tgz` 完整路径，启用并重启。手机安装 ARM64 APK；使用相同 DeepSeekBot 项目签名的旧版可直接覆盖更新，主机上的 Bot 和聊天保留。首次连接时，在电脑 DS Bot「设置 → 移动设备」启用手机连接，手机扫码，电脑批准。使用时保持主机运行。

### 验证与平台支持

发布前本地通过 758 项测试：插件 653、App 69、SDK 28、设备辅助脚本 8，另通过 App 类型检查、生成客户端一致性与 lint。上游同步完成 62 步隔离官方 DSH／mock 联调；UI 检查包含 Android HTTPS 配对、键盘与长输入，以及中英文、夜间模式的页面复查。标签工作流再次验证、构建并以原有项目证书签名两种 Android 架构。

iOS 源码已提供，本版不提供 IPA，尚未完成 iOS 编译与真机验证。公网 IPv6 跨运营商真机连接、读屏器与新增文件卡片的原生视觉检查未全覆盖。语音／桌面浏览器需要相应主机服务；无需 FCM/APNs 的 Android 通知依赖接收服务仍在运行及主机可达，不覆盖强制停止。模拟模型与模拟器结果不代表所有真机或生产模型行为。

## English

This coordinated `0.1.1` plugin and Android release ports upstream [v0.1.5](https://github.com/Fei2411/DeepSeek-Bot/releases/tag/v0.1.5), source `20ebc9213cbbde7249d71786765f86be00dc6663`, and adds direct IPv6 access and mobile working-folder management.

- Select usable private/public IPv6 addresses with automatic IP certificates and bracketed pairing URLs. Cross-network access needs IPv6 on the phone and incoming firewall access; no domain or project-hosted relay is required.
- Choose a host project, type a folder path, or browse directories from Bot/group details. Folder changes retain history in fresh parts. Horizontal breadcrumbs and separate browsing/path entry simplify selection; older hosts without the API show an upgrade message instead of reporting a false save.
- View PTC sub-tool activity, delivered-file metadata and available host file-change summaries. These file cards are metadata, not download links; message attachments retain their existing download/preview behavior.
- Localize plugin lifecycle, metadata and thinking levels, compact plugin tabs, enlarge message detail touch targets to 44dp, and align default blue controls with `#3964FE`. Floating controls, shadow-free capsules, long-press message actions and dark mode remain available.
- Include upstream fixes for questions, greetings, unread-message backpressure, provider conversation identity, memory retries, PTC group activity, native desktop file cards, work-detail preferences and DSH home resolution.

Install `ds-bot-0.1.1.tgz` on DSH and the signed `dsbot-android-arm64-v0.1.1.apk` on phones; the x86_64 APK is for emulators. Update both ends together, enable the plugin and restart DSH. Same-project signed APKs support in-place updates and host conversations remain intact. Pair by scanning the host's QR and approving the phone on the computer. Keep the host running. Verify downloads with `SHA256SUMS`; `DeepSeekBot.cer` is the public signing certificate.

Pre-release validation includes 758 local tests, TypeScript, generated-client consistency, lint, 62 real DSH/mock integration steps for the upstream sync, and Android HTTPS/keyboard/multiline checks plus Chinese/English light/dark UI review. The tag workflow repeats validation and builds/signs both Android architectures using the existing identity. iOS source is included without an IPA or verified iOS build/device test. Cross-carrier IPv6 device access, screen readers and native visual checks of new file cards are not fully covered. Runtime Android notifications still require a running receiver and reachable host; force-stop is not covered.
