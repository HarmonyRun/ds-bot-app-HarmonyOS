## 关键行为实证

- 桌面没有批准时，配对请求不能取得设备凭证；撤销设备会关闭连接并使刷新失败。
- 同一个设备的并发重复发送仅执行一次。模拟主机已经接受但手机没收到回执，再次操作会查询原请求，而不是创建新请求。
- 模拟丢失回执后撤销旧设备，再批准新设备：旧发送记录不可重试，实际提交次数保持为 1。归档旧记录后输入框为空，不复制并重发原消息。
- 停止当前回复保留排队消息；HTTP 与 WebSocket 都能显示队列，单条移除不影响另一条，下次发送可唤醒剩余队列。
- 图片与 UTF-8 文本真实进入 DSH；图片下载需要认证。损坏图片在准入时被拒绝，回执保留明确拒绝状态。
- 音频适配用真实 ffmpeg 处理 20 秒 M4A，检查规范 PCM16 WAV、超时长拒绝、取消和禁止播放列表联网。单元测试使用模拟识别服务；另外执行了隔离的真实 SenseVoice 识别检查。
- 使用本地 flite 合成 3.305 秒英文语音：`The weather is clear today. Please bring a glass of water.`。真实 SenseVoice 两次均识别为 `The weather is clear today, please bring a glass of water.`，仅标点不同；识别耗时分别为 0.152 秒和 0.164 秒，包含首次模型下载与准备的整个检查耗时约 121 秒。这是单句功能验证，不能代表复杂场景或手机实录质量。检查不需要模型 API 密钥，完成后已释放服务并退出进程。
- 随后通过实际移动适配器 `transcribe` 输入 3.328 秒 M4A，经 ffmpeg 转换并调用公开识别服务，取得相同文本，识别耗时约 0.145 秒。这次复用已校验模型缓存，整个检查约 1.99 秒；完成后识别工作进程数量为 0。
- 不确定回执只在公开历史或队列提供“已接受”证据时恢复；找不到证据不会触发自动重发。
- 桌面与手机共享工具审批请求，测试覆盖两端决定、过期/取消、拒绝和重复决定；请求不是普通Bot提问，也不改变主机ask/never策略。
- 本轮修复了已知敏感值在持久历史/实时投影间脱敏不一致的问题，历史、实时消息和队列统一走安全投影。敏感写入失败只显示固定文案，不反射provider错误码或新输入值。
- 浏览器联调使用真实数据验证Paper主题跨设备同步、主Bot/群规则、中文General设置、Memory确认删除、任务、用量及历史上下文；未伪造业务响应。当前Web profile默认提供Schedule服务，其他profile要实际启用该公开服务；无需安装已经退役的schedule bundle。
