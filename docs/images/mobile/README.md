# App screenshots

These screenshots were captured from the signed local Android review build containing the floating-control fixes (App 0.1.0, Android versionCode 6), running in an Android API 30 emulator against an isolated DSH host and the repository's scripted mock model.

Each locale includes the conversation home, Bot chat, dark chat, group chat, Bot creation and Tools & skills. UI language changes independently of the demonstration messages, which keep their original language.

The native capture includes only the App content viewport below Android's status bar; Android navigation chrome is excluded. App pixels are not retouched, and no generated scenes or device frames are added. Pairing inputs and credential forms are not included. The pictures demonstrate the interface, not production-model answer quality.

The earlier v0.1.0 release binaries were withdrawn. These screenshots show the corrected review build; they do not establish a new published release. The APK checksum and capture viewport are recorded in [screenshots.json](screenshots.json).
