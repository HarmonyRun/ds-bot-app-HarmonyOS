# App screenshots

These screenshots were captured from the published, signed [Android v0.1.0 release](https://github.com/QingJ01/DS-Bot-App/releases/tag/v0.1.0), versionCode 15, running in an Android API 30 x86_64 emulator against an isolated official DSH host and the repository's scripted mock model.

Each locale includes the conversation home, Bot chat, dark chat, group chat, Bot creation, settings, Tools & skills, and the new capability library. UI language changes independently of the demonstration messages and configured Bot/capability names. The capture uses reduced motion and the default brand accent.

The native capture contains only the App content viewport below Android's status bar; Android navigation chrome is excluded. App pixels are not retouched. Pairing inputs, QR codes and credential forms are not included. The pictures demonstrate the interface, not production-model answer quality.

The release source commit, APK checksum, native viewport and individual image checksums are recorded in [screenshots.json](screenshots.json). These captures replace the older local-review images.

The [plugin Mobile devices page](plugin-devices.zh.png) is current DSH Web browser content, captured before generating any pairing QR. [chat-polish.en.png](chat-polish.en.png) uses the same current App capture as chat.en.png so older documentation links continue to work. Their source details are recorded in [ui-polish.json](ui-polish.json).
