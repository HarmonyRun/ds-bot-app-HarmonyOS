# 移动端界面与中英文打磨

本轮参考用户提供的会话与列表截图，优化现有 React Native 客户端。保留 DS Bot 自有角色图案、真实主机接口和权限流程；没有复制参考产品的图标、头像或消息内容。

## 视觉调整

最新一轮按用户五张参考截图重做页面结构，取消侧边栏。

- 主页使用全屏会话列表。左上头像打开整页设置，右上搜索与新增保持悬浮圆形按钮。主 Bot 单独居中展示；会话行显示头像、名称、最近消息、日期与实际未读状态。向下滚动后，被滚过的未读会话形成可点击的未读提示。主页没有通知或用量快捷入口。
- 设置采用关闭按钮和浅灰分组卡片：实际主机与用量、工具与技能、Bot 与群聊、定时任务、Bot 电脑、通知与外观等。没有虚构账号、配额百分比或主机不支持的开关。技能、插件、连接器从工具与技能进入。
- 新建 Bot 使用大头像、居中名称输入、13 个角色选择与 11 个颜色选择，以及底部创建按钮。点击大头像可选择全部角色；名称为空时禁用创建。创建经真实接口保存，进一步的指令、模型与照片编辑仍在 Bot 详情中。
- 新建群聊先搜索并选择 Bot；选择至少两位成员后启用下一步，再设置群名和管理员。创建使用真实群聊接口。
- 普通消息不再显示三个点或常驻操作条。长按已提交消息进入回复、表情、复制、下载、分享和朗读菜单；聊天顶部的会话选项保留。
- 聊天顶部使用返回圆钮与角色标题胶囊，用户消息气泡日间为 `#EDF3FE`，夜间为 `#333333` 配 `#FFFFFF` 正文；Bot 回复恢复原主题的气泡与文字颜色，输入栏与底部控件采用胶囊布局。附件浮层靠近输入栏，提供选择文件、拍照、附加图片及引用会话入口，大小限制仍由真实校验执行。
- 已完成的 `ask_user` / `ask_user_question` 内部回执隐藏；提问卡片、错误记录和运行中的回执保留。工具结果使用类型与状态卡片，并提供详情界面。
- 界面继续使用 DS Bot 自有角色和标准 Feather / MaterialCommunityIcons。系统状态栏、参考产品的账号与消息内容不属于复制范围。

## 消息操作与夜间模式更新

- 默认蓝色统一为 `rgb(57, 100, 254)` / `#3964FE`，应用于默认蓝色主题、强调按钮、未读标记与蓝色角色。自定义主题和强调色继续按用户偏好生效。
- 长按消息打开紧凑面板，顶部直接选择表情，附带两行消息预览；回复、复制、分享、下载和朗读采用图标与文字。复制成功、引用或回应后自动收起。系统分享在面板退出后启动，iOS 等待原生 `onDismiss`，Android 等待淡出完成。
- 单人聊天的消息不显示头像；按最新截图，聊天标题恢复头像＋名称的独立悬浮胶囊。群聊保留群头像，并在发言者名称旁显示 Bot 头像，包括历史片段中的发言者。
- 输入栏两侧使用 20 的边距；加号与发送按钮中心对齐，多行输入时保持底部基线一致。
- 主页左上入口采用项目已有的鱼形角色，长按可重播进入动画。每次冷启动跳出、眨眼并淡入应用；系统开启“减少动态效果”时使用静态短过渡，不依赖网络，普通动画时长约 1.4 秒；系统偏好读取与动画播放分别设置兜底退出，避免慢查询截断眨眼。覆盖期间底层页面透明并从读屏树隐藏，避免额外绘制与焦点竞争。
- 跟随系统夜间模式调整主页、聊天、消息操作、附件、设置与管理页面；鱼形入口的眼睛保持清晰。

## 中英文

设置 → 通用 → 语言可选择跟随主机、跟随系统、English 或简体中文。切换即时生效并按主机保存。主机采用系统语言偏好时，手机会跟随自身系统语言。

翻译范围包括聊天操作、技能管理、插件界面、桌面浏览器、工具结果、通知设置、错误、日期、定时任务摘要及原生后台通知。名称、模型标识、用户消息、技能正文、工具输出等内容保留原文。

原生接收服务随语言切换更新通知标题、通用正文和 Android 停止操作，不重新登记凭据、不清空游标。后台仍遵守 Android/iOS 原有生命周期限制；云推送依然可选。

## 同步修复

- 通知页面可见且在线时每 5 秒刷新，并在回到前台时刷新；失败显示错误，退出页面取消请求，保留旧数据。
- 桌面浏览器区分主机服务不可用、未打开 Bot 浏览器和尚未授权控制。
- 自定义强调色按对比度选择文字颜色；中间亮度的边界颜色必要时使用纯黑，避免中灰底白字的问题。
- 主 Bot 选择与 Bot 编辑使用不同的可访问名称。
- 链接使用与浅色/深色气泡匹配的高对比度颜色；搜索结果按完整词条处理单复数，中文不再多出英文 s。
- 聊天输入区计入顶部安全区，避免系统键盘遮挡发送按钮底部。

## 构建翻译文件

Android 的 JS 打包任务现在显式跟踪 `src` 下的 JSON 翻译文件，避免只改文案时增量构建复用旧包。此配置通过 Expo config plugin 保留，重新 prebuild 后仍生效。

## 消息颜色与底部胶囊（2026-10-13）

用户消息颜色独立于主机主题预设：日间 `#EDF3FE` 配深色正文，夜间 `#333333` 配白色正文。按用户随后修正，Bot 回复及空会话提示恢复原主题的气泡与文字颜色。底部输入栏、加号、语音、发送/停止、引用卡片、待发送附件、状态提示与群成员进度统一圆角；加号为 64×56，语音/发送保留至少 44 的触控高度。多行输入时仍沿底部对齐，引用与附件保留独立移除按钮。新版安装包与验收记录位于 `/workspace/artifacts/dsbot-capsules-20261013/`。

## 底部悬浮与透明空隙（2026-10-13）

聊天列表延伸到整个可见区域，底部输入控件改为绝对定位的悬浮层。底部包裹层、控件间隙与引用卡片的换行空隙没有整块背景，并允许触摸穿透；只有各胶囊本身保留背景。列表按实际测量的悬浮层高度增加末尾滚动余量，保证最后一条消息能完整滚出控件上方。聊天页底部安全区由悬浮层自身处理，键盘展开时减少底部留白；iOS 的悬浮层放在 KeyboardAvoidingView 内部的 flex 内容区域。消息颜色沿用上一轮的最终要求。交付目录为 `/workspace/artifacts/dsbot-floating-footer-20261013/`。

## 输入框弧度与发送颜色（2026-10-13）

输入框外层改为固定 24 dp 圆角，随多行高度增长时不再使用无限圆角形成椭圆。发送及重试箭头使用品牌蓝 `#3964FE`（RGB 57,100,254）背景与白色箭头，日间和夜间一致。悬浮层的透明空隙、末尾滚动余量沿用。交付目录为 `/workspace/artifacts/dsbot-composer-shape-20261013/`。
