# 上游更新移植与悬浮聊天顶栏

本轮依据用户提供的更新帖：https://x.com/Fei2411/status/2109682023438925979 。固定移植上游 `Fei2411/DeepSeek-Bot` 提交 `84571450a3ce91413f8c7cf005c84a7bc7754efd`，而不是跟随之后的主分支变动。抓取时只有 v0.1.2 标签；帖子介绍的 0.1.3 内容仍在 CHANGELOG 的 Unreleased 区域，移植时插件清单保留上游实际版本 0.1.2。本分支首个配套发布将插件和 App 版本统一为 0.1.0，使用独立于上游的版本序列；已移植的上游功能保留。

## 移植范围

同步上游 0.1.1、0.1.2 和本次主分支的新增与修复，包括：Bot 点名与会话引用、工作中收到消息后的下一步转交、Main Bot 停止其他 Bot、Bot 修改自身资料、群聊等待审批时继续轮次及迟到回复、群内追加消息、思考级别和权限沿用到新分段、模型拒绝请求后的恢复、内存摘要预算、当前时间注入、存储错误与损坏备份、删除对象时清理定时任务、日志脱敏、更新来源、关于页面和用量页面。四处与已有移动端代码的冲突已逐项合并；Mobile Bridge、通知、插件/Skills 管理和桌面浏览器控制保留。

## 手机适配

- 聊天顶栏改为三个独立悬浮控件。返回和更多各为圆钮，头像与名称合在单独胶囊内；整个横条没有背景或手势遮挡，消息可在空隙与后方滚动。最新要求恢复单人聊天标题头像，消息正文继续只在群聊显示发言头像。
- `@` 按光标位置显示 Bot，单人会话排除当前 Bot，群聊显示成员和“所有人”。选中写入名字，代码、文件路径、链接和网页地址不会被当作 Bot 点名。手机端使用上游同一纯函数规则绘制点名。
- 输入栏 `+ → 引用会话` 选择其他 Bot 或最近普通会话。引用显示成可移除小卡片，编码随草稿保存，不显示在输入框中；发送仍走原有稳定请求 ID 和回执流程。只读上下文由 Harness 的公开会话引用服务准备。
- 根据当前公开服务契约，单条消息最多引用三个会话。服务端再次验证引用，排除当前会话、隐藏群成员会话、子 Agent 和空会话，并在附件上传之后重新检查权限边界。旧主机没有引用服务时显示升级提示。
- Bot 模型界面提供主机实际返回的思考级别；默认使用模型自身设置。更换模型清除旧思考级别。权限选项只采用主机提供的预设，自动审查不作为永久 Bot 权限。
- 群聊显示成员工作/等待批准状态；群聊正文和详情页都能处理审批。群审批由上游统一拥有，手机不再用另一条 promise 拦住群轮次；设备撤销、成员移除、归属变化或重复回答均拒绝。
- 同一轮多个步骤的思考合为一个展开入口，原始历史和缓存不被改写。
- 新增“关于 DS Bot”：手机端、插件与 DSH 版本，检查更新、已验证的 DSH 更新、源码/发行说明/反馈/Star 链接。更新需要在界面再次确认；桌面打包版通过其自己的更新器更新。
- 夜间模式、品牌蓝 `#3964FE`、中英文、长按消息操作以及鱼形入口延续。

## 验证与安装

在隔离的官方 npm DSH `0.2.0-rc.2` 和 mock 模型上验证，没有修改 DSH 源码或访问用户自己的 DSH 数据。插件 533、手机端 45、SDK 25 项测试通过；生成客户端一致性、TypeScript 和 oxlint 通过。真实 DSH 的 32 步集成流程通过。ARM64 与 x86_64 Android release 构建通过。

交付目录：`/workspace/artifacts/dsbot-upstream-20261012/`。新功能的主机 API 也有变化，请同时更新 DS Bot 主机插件与手机 APK。x86_64 APK 仅用于测试模拟器，带专用测试证书；ARM64 APK 使用正常系统 TLS 信任。iOS 未在本轮编译或实测。

云端无 KVM 模拟器首次启动发生 System UI 无响应，已用实际系统弹窗处理后继续验收。原生页面结果、截图、安装包 SHA-256 和测试环境清理记录单独保存；不将编译通过替代界面验收。

本轮完成 13 张原生截图验收，包括浮动顶栏与穿透滚动、单人/群聊点名、加号引用会话及实际发送、夜间中英文、关于页、思考级别与工作区权限的实际保存。发送验收采用隔离 mock 模型，确认 Harness 将引用转换为只读会话快照；未使用真实模型密钥。详见 `design-qa.md` 和交付目录的图册与 JSON 证据。
